# Review of the doc pack (2026-10-25, evening)

> Read this first if you only have 10 minutes. It says what was checked, what was wrong, what was changed (D-031 to D-036), what was challenged and **kept**, and every scenario that could go wrong with its fallback.
> Everything marked ✓ below was checked live on 2026-10-25 against the real sources. Items I could **not** check from here are listed in §7.

## 1. Verdict

The plan is strong. The flagship is real, the architecture is sound (deterministic code first, one agent with real experiments, proof by byte comparison, sealed benchmark), and the guardrails are unusually thorough. I changed only what I could show was wrong or clearly better. **No architecture change, no change of flagship, no change of model roles.**

Three things needed fixing because they could cost points or credibility:

1. **The flagship's answer is public, and the agent is handed it.** Debian's notes tag all 13 packages with `timezone_variant_in_argparse_manpage`, and that catalogue entry names the tool and the timezone cause. The docs assumed the hint was generic. A judge reading the investigator prompt could say the demo was scripted. Fix: blind run as the headline (D-031), honest wording (`FLAGSHIP_CASE.md` §1.1).
2. **"Mirrors Debian CI exactly" was not quite true.** CI varies the kernel on amd64 and adds 6 h 23 min to the clock; the docs said the kernel was not varied. Fix: D-035, wording changed everywhere to "except the kernel".
3. **The Must-have campaign could be blocked by an unrelated bug.** Building a patched argparse-manpage `.deb` hits the same Python 3.15 failure that blocks Debian. Fix: verify by overlay first (D-034).

And three cheap additions that directly serve the judging criteria: keyless replay (D-032), independent builders on GitHub runners (D-033), and a `/judges` evidence page (D-036).

## 5. Decisions I challenged and kept (with the reason)

| Decision | Challenge | Why it stays |
|---|---|---|
| Docker-first, Sandboxes as accelerator (D-022) | Sandboxes are the headline Token Factory feature for this track | Access isn't granted; a blocker can't be on the critical path. Inference is a genuine runtime Token Factory call (Stage 1). Keep the Day-0 email and the interface. With D-033 the "independent machines" claim no longer depends on it |
| Ultra investigator, Super patcher, Ultra critic, fast model for scout/signatures | Fewer models would be simpler | Role split is measured by bake-off and ablation, which is exactly what judges asked to see |
| `probe` experiments instead of reading the diff | One-shot would be cheaper | Experiments are the "run and test code" part of the track and the reason the toolchain cause is found |
| Policy guard + diff computed by harness (D-025) | Extra code | Removes malformed-hunk failures and the "cheated by skipping tests" objection |
| Benchmark v2 with three tracks (D-026) | Tags are noisy ground truth | Honest, cheap, and Track B (twin build is the judge) carries the objective claim |
| Max 3 rounds, 2 candidates (D-007) | More candidates → higher yield | Laptop capacity; Actions could raise it later, but don't expand scope now |
| Tavily off in benchmark, on in product (D-010) | Tavily everywhere would use more of the prize | Benchmark integrity matters more than the bonus |
| Static GitHub Pages site (D-030) | A live app would look richer | Must survive to 15 Dec with no server; replay covers interactivity |
| No fine-tuning, no NeMo Agent Toolkit | — | Not available / deprecated; not needed for the story |
| Flagship = argparse-manpage cluster | Debian already labelled it | Still the best verified end-to-end case: real, stuck, upstream still broken, 14th package unlabelled. Only the *wording* and the *blind run* change |

## 10. Follow-up review of this pass (v3, Oct 25 night)

**Verdict:** the v2 pass makes the project better and should be kept. Every factual claim spot-checked holds: the catalogue entry and its wording, the invented name `timezone_specific_date_in_manpage`, the trailing `PATH` colon, the +6 h 23 min clock, the amd64 kernel variation, no open upstream issue or PR about the timezone bug, and all 14 fixtures parse. The blind run and overlay-first decisions are the two most valuable changes. Its weaknesses were one design bug in the new Actions workflow, a few leaks in the blind run, and scope: it added about 10 hours and cut nothing.
